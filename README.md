Управление односвязным списком (Python)
Консольное приложение для работы с односвязным списком пользователей. Проект демонстрирует базовые операции со структурами данных на Python.

📋 Функциональность
Добавление пользователя — новый элемент добавляется в конец списка

Просмотр всех пользователей — отображение всего списка с подсчётом количества

Удаление последнего пользователя — удаление элемента из конца списка

Вставка по индексу — добавление нового пользователя на указанную позицию


🚀 Быстрый старт
Клонируйте репозиторий:

bash
git clone https://github.com/username/linked-list-manager.git
Перейдите в директорию проекта:

bash
cd linked-list-manager
Запустите приложение:

bash
python main.py
